# Landing Page (Study Project)

Учебный лендинг, сверстанный на чистом HTML и SCSS.
Проект создан для практики вёрстки и работы с Git.

## 🛠️ Tech Stack
- HTML5
- SCSS (Sass)
- Git / GitHub

## 🚀 How to Run
1. Клонировать репозиторий
2. Открыть `index.html` в браузере

Для работы с SCSS используется компиляция в CSS (через VS Code).
